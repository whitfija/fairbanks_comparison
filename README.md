# fairbanks_comparison
Scripts for initial comparison of data from Fairbanks radiosondes with ERA5 and HRRR profiles.

# required packages
## weather data collection
siphon - radiosonde
herbie-data - hrrr-ak
cdsapi - era5

## file reading
cfgrib - hrrr grib2
netCDF4 - era5

## data processing
xarray
pandas

## analysis/plots
metpy
matplotlib
